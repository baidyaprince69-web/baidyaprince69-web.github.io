# Violin Prince — Official Root Website

This repository publishes the user-level GitHub Pages website:

- https://baidyaprince69-web.github.io/

The main music portfolio remains in its project repository:

- https://baidyaprince69-web.github.io/violin-prince-website/

## Brand assets

- `favicon.png` — official square Violin Prince mark used by search engines and browsers.
- `apple-touch-icon.png` — same brand mark for touch-icon surfaces.

The favicon file is deliberately kept at a stable root-level URL. The homepage references it with an absolute path (`/favicon.png`).

## GitHub Pages publishing

Publish from the `main` branch and the repository root (`/(root)`) in **Settings → Pages → Build and deployment**.
