# Violin Prince — Official Artist Website

This repository publishes the central artist website for **Violin Prince (Prince Baidya)**:

- https://baidyaprince69-web.github.io/

## Website roles

- **This root website** is the official artist home: artist introduction, selected performances, official profile links, and the gateway to the music collection.
- **Music collection:** https://baidyaprince69-web.github.io/violin-prince-website/
  - The collection retains the full music explorer, mood discovery, song library, individual performance pages, request form, textures, animations and listening controls.

The two websites link to each other so visitors can move between the artist identity and the complete listening experience.

## Brand assets

- `favicon.png` — official square Violin Prince logo used by browsers and search engines.
- `apple-touch-icon.png` — official touch icon.
- The official root favicon is kept at a stable hostname-level URL: `/favicon.png`.

## Search and discovery

- Homepage canonical URL: https://baidyaprince69-web.github.io/
- Root sitemap: https://baidyaprince69-web.github.io/sitemap.xml
- Collection sitemap: https://baidyaprince69-web.github.io/violin-prince-website/sitemap.xml
- Video sitemap: https://baidyaprince69-web.github.io/violin-prince-website/video-sitemap.xml

The root `robots.txt` advertises all three sitemap locations.

## GitHub Pages publishing

Publish from the `main` branch and the repository root (`/(root)`) in **Settings → Pages → Build and deployment**.
